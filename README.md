# Business-Projections

Iron Neck revenue projection model and dashboard (Shopify, Amazon, D/D/O, net income) through Dec 2027.
Live dashboard: https://ironneck-revenue-projection.netlify.app

- `model/` data store, loader, model, daily refresh script
- `site/` static dashboard deployed to Netlify (publish dir `site/public`)
- `REFRESH.md` daily refresh runbook
